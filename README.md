# Collect to Lark

一款 Chrome 浏览器扩展，用于将网页收藏到飞书多维表格。

## 功能特性

- **一键收藏**：通过右键菜单、工具栏按钮或快捷键快速收藏当前页面
- **智能分类**：支持分类、标签、备注等字段，自动同步飞书多维表格选项
- **快捷键**：可自定义快捷键（默认 `Option+S`），支持全局触发
- **字段自动创建**：新增分类/标签时自动在飞书表格中创建对应选项
- **创建人记录**：自动填充预设的创建人昵称

## 技术栈

- **框架**：React 18 + TypeScript
- **构建**：Vite 6
- **样式**：Tailwind CSS
- **扩展**：Chrome Extension Manifest V3

## 项目结构

```
src/
├── background/       # Service Worker（处理飞书 API 请求）
├── content/          # Content Script（收藏弹窗 UI）
├── options/          # 设置页面
├── popup/            # 工具栏弹出面板
└── shared/           # 共享模块
    ├── feishu.ts     # 飞书 API 封装
    ├── hotkey.ts     # 快捷键处理
    ├── storage.ts    # 本地存储
    └── types.ts      # 类型定义
```

## 安装使用

### 本地安装

1. 运行 `npm run build` 构建项目
2. 打开 Chrome，访问 `chrome://extensions/`
3. 开启「开发者模式」
4. 点击「加载已解压的扩展程序」，选择 `dist` 目录

### 配置

1. 点击扩展图标，进入设置页面
2. 填写飞书应用信息：
   - **App ID** 和 **App Secret**：从[飞书开放平台](https://open.feishu.cn/)创建应用获取
   - **飞书多维表格链接**：粘贴你的多维表格 URL
3. 选择目标数据表
4. 设置创建人昵称（可选）

### 飞书应用权限

需要在飞书开放平台为应用添加以下权限：

- `bitable:record` - 读写多维表格记录
- `bitable:field` - 读写多维表格字段

同时需要将应用添加为多维表格的协作者（「可编辑」权限）。

### 飞书多维表格字段配置

在目标数据表中创建以下字段（字段名需严格匹配）：

| 字段名 | 字段类型 | 说明 |
|--------|----------|------|
| 内容标题 | 文本 | 网页标题 |
| 网页说明 | 文本 | 网页描述（meta description） |
| 网页地址 | 超链接 | 收藏的网页 URL |
| 收集时间 | 日期 | 收藏时的时间戳 |
| 创建人 | 文本 | 预设的创建人昵称 |
| 分类 | 多选 | 内容分类，支持自动创建新选项 |
| 标签 | 多选 | 内容标签，支持多个，支持自动创建 |
| 备注 | 文本 | 用户自定义备注 |

> **注意**：分类和标签字段必须是「多选」类型，插件会自动将新选项同步到飞书表格。

## 快捷键

| 操作 | 默认快捷键 |
|------|-----------|
| 打开收藏弹窗 | `Option+S` (Mac) / `Alt+S` (Windows) |

可在设置页面自定义修改或关闭。
